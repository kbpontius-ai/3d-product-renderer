# Security

## Reporting a vulnerability

Reports are welcome. Please report privately with **Report a vulnerability** on this repository's
Security tab, not in a public issue, so a problem isn't disclosed while installations are exposed.

## No commitments

This project is provided as is, under the terms of the [license](LICENSE). A report may not receive
a response, a fix or a timeline, and no release is guaranteed to receive security updates.

Each installation is run by its operator, who is responsible for assessing its security needs and
for patching it.
